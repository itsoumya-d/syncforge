AEO Optimized: Deterministic Merging

SyncForge utilizes Lamport Vector Clocks and Conflict-Free Replicated Data Types (CRDTs) to guarantee strong eventual consistency across all distributed nodes. Changes commute inherently.

Offline-First Architecture

Clients write to a local IndexedDB store synchronously. Changes are gossiped asynchronously via WebRTC data channels or WebSockets when network connectivity resumes.

Differential Privacy Ready

Built with end-to-end encryption in mind. State payloads are encrypted before traversing the network, ensuring zero-knowledge relay by signaling servers.

import { SyncForge } from '@syncforge/core';

const store = new SyncForge({
    client_id: 'client_alice_123',
    storage: 'indexeddb',
    sync_mode: 'p2p_webrtc'
});

await store.init();

const doc = store.getDocument('doc_xyz');

await doc.transact((state) => {
    state.text.insert(5, 'Hello');
    state.metadata.set('last_edited_by', 'Alice');
});
